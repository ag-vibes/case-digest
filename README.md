# Case Digest

Case Digest собирает рекламные и маркетинговые кейсы за последние семь дней,
извлекает полный текст, удаляет дубликаты, оценивает материалы по прозрачной
шкале и готовит предварительный Telegram-дайджест.

## Продуктовые правила

- До 5 российских и до 5 зарубежных кейсов — это максимум, а не квота.
- Оценка: новизна 30%, культурный/поведенческий инсайт 25%, ясность механики
  20%, качество реализации 15%, доказательность 10%.
- Не включаются performance-маркетинг, обычные скидки и промо, кадровые новости,
  отчёты и материалы без конкретной реализованной механики.
- Кейс без рабочего первоисточника не публикуется.
- Telegram-вовлечённость используется только как discovery-сигнал.

## Безопасные режимы

```bash
python digest.py --mode check
python digest.py --mode dry-run
```

`check` проверяет доступы без сбора и публикации. `dry-run` создаёт:

- `artifacts/preview.md` — читаемый предпросмотр;
- `artifacts/report.json` — отчёт источников, оценок и причин отклонения.

Папка `artifacts/` исключена из Git. Workflow запускается только вручную,
не содержит расписания и не предлагает режим публикации.

## Источники

Источники редактируются в `sources.yaml`:

- Sostav, AdIndex, Adweek и Famous Campaigns через RSS;
- The Drum через официальный sitemap статей;
- Marketing Week через Google News discovery и Tavily/direct extraction;
- публичные Telegram-каналы через отдельную пользовательскую Pyrogram-сессию.

Понравившиеся сообщения с ❤️ читаются непосредственно из `@adscasedigest` и
используются как мягкие примеры для следующей оценки. Отсутствие ❤️ считается
нейтральным сигналом. Реакции и профиль предпочтений в Git не записываются.

LBBOnline намеренно исключён.

## Переменные окружения

В GitHub Actions Secrets:

- `OPENROUTER_API_KEY`
- `TAVILY_API_KEY`
- `TELEGRAM_TOKEN`
- `TELEGRAM_CHAT_ID`
- `API_ID`
- `API_HASH`
- `SESSION_STRING`

Секреты, реакции и персональный профиль предпочтений нельзя сохранять в
публичном репозитории.

## Локальная установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest
```

Публикация реализована в CLI, но требует отдельного `--mode publish` и точного
`--confirm-channel`. Использовать её можно только после проверки предпросмотра.
